    Twitchで開く

    なぜ Twitch へのログインが必要なの？

    クリップの一覧は Twitch の公式 API から取得しています。この API は、公開されているクリップを読むだけでも、ログインして発行される「アクセストークン」がないと使えない決まりになっています。そのため、検索の前にログインをお願いしています。

    • ログインは Twitch 公式の画面で行います ボタンを押すと Twitch のログインページ（id.twitch.tv）に移動します。アドレスバーで確認できます。パスワードをこのサイトに入力することはなく、このサイトに届くこともありません。
    • 読み取り以外の権限は求めません 求める権限はゼロです。チャットの送信、フォロー、配信設定の変更、メールアドレスなど個人情報の閲覧はできません。使うのは、誰でも見られるクリップとチャンネルの情報だけです。
    • トークンはこのブラウザの中だけに保存されます このサイトにはTwitch以外へのサーバー通信がありません。トークンはお使いのブラウザに保存され、Twitch の API に問い合わせるとき以外には送信されません。
    • いつでも連携を解除できます 「ログアウト」を押すとトークンは無効になります。Twitch の「設定 → 接続」からも、いつでも連携を解除できます。
    • ソースコードを公開しています このプロジェクトは OSS として公開しており、どなたでもソースコードを確認していただけます。ログインの処理やトークンの扱いも、実際のコードでご確認ください。github.com/CloudCandy-dev
